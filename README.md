# astrbot_plugin_xb2img (双图助手 xb2img)

🖼️ 一个精致小巧、功能强大的 AstrBot QQ 图片双图合成插件。

- 📦 项目主页：https://github.com/imsuperone/xb2img

---

## 🌟 核心特性

- 🎭 **一张图片，两副面孔**：聊天窗口列表静止显示预览图 A，点击查看原图后播放加载展示隐藏图 B。
- 🎞️ **原生动图驱动**：基于 APNG 动画帧协议标准合成，支持全彩、不损失色彩深度，两张图片内容可完全独立不同。
- ♾️ **丝滑无限循环**：首帧展示静态预览画面，点击大图即刻触发动画无限循环播放。
- 📦 **文件真名保障**：通过 OneBot11 协议标准透传文件名（格式为 `fax_年月日时分秒+序号`），保证原汁原味文件格式传输。
- 💾 **自动极限压缩**：内置动态分辨率压缩 Ladder，自动控制生成文件体积在 1MB 左右，极速秒发兼具极限省流。
- 🛡️ **高并发任务排队门**：内置轻量级并发调度网关（上限 5 个任务串行处理），防止多人并发合成打爆服务器。
- 🧹 **发完即清，零盘占用**：处理完成后自动秒级清除中间临时缓存，不留任何冗余文件，安全轻量。

---

## 🚀 聊天指令

| 指令 | 说明 |
| :--- | :--- |
| `/双图 <图A> <图B>` | 合成双图，默认输出 `.png` 格式（支持本地路径或图片 URL） |
| `/双图` (附带两张图片) | 直接发送指令并附带两张图片一起发送即可自动识别合成 |
| `/双图 --apng <图A> <图B>` | 使用 `--apng` 变量指定输出后缀为 `.apng` 格式 |

---

## 💡 实现原理

- 🧩 **APNG 动图帧差分**：将两张独立图片打包为包含 `acTL/fcTL` 动图块的 APNG 图像结构。
- 👁️ **列表预览机制**：第 1 帧设置为静态预览图 A（仅闪过 500ms），QQ 聊天窗口默认仅渲染首帧静态后备图，因此在外部列表完整呈现图片 A。
- 🎬 **大图播放机制**：点开原图查看时，客户端触发动画解码并完整播放后续帧（隐藏图 B），从而呈现“点开变另一张图”的神奇视觉效果。
- 🚀 **协议原图透传**：通过 NapCatQQ / OneBot11 原生消息通道以原字节直接上报发送，避免被平台二次转码压缩损毁动图结构。
