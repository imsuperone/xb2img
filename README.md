# xb2img

🖼️ AstrBot 高能 xb2img 合成插件，现场将两张图片合成为一张拥有特殊动图结构的 PNG 图片。实现聊天列表静止显示预览图 A，点击加载原图后展示图 B 的奇妙视觉效果。

- 📦 项目主页：https://github.com/imsuperone/xb2img
- 🔌 插件 ID：`astrbot_plugin_xb2img`
- 📌 版本：`v1.0.8`，要求 AstrBot `>=3.4.0`，平台 `aiocqhttp`

---

## 🌟 核心特性

- 🎭 **两张图两副面孔**：聊天窗口列表中静止显示预览图 A，用户点击加载查看原图后播放展示图 B。
- 🔄 **全彩无限循环**：采用标准 APNG 帧序列组织，全彩 RGB/RGBA 保留，杜绝降色深导致的斑驳花屏。
- 💾 **自动梯级压缩**：内置智能自适应分辨率算法（1080px 起按面积比估算降档，最低 128px，最多 6 轮），严格将最终生成图片控制在 1MB 左右。
- 🚦 **并发排队防护**：自带全局任务排队控制门（最多 5 个任务并发排队），防止多人高频触发压垮服务器性能。
- 🧹 **内存与临时文件无残留**：任务处理与发送完毕后立即彻底清空本地临时目录，零残留不锁盘。
- ⏱️ **交互体验贴心**：处理耗时自动提示“正在处理 xb2img 中...”，生成完毕后自动撤回提示并发送原图，保持聊天窗口整洁。
- ⚡ **底层原图透传**：采用底层的 OneBot11 原图消息通道直发，避免平台压缩转码破坏动图结构。

## 🚀 安装

1. 放入 AstrBot 插件目录：
   ```bash
   git clone https://github.com/imsuperone/xb2img.git data/plugins/astrbot_plugin_xb2img
   ```
2. 安装依赖并重启 AstrBot，插件自动加载：
   ```bash
   pip install -r data/plugins/astrbot_plugin_xb2img/requirements.txt
   ```
3. 重启 AstrBot，在 WebUI 插件列表中启用 `xb2img` 即可开始使用。

## 🚀 聊天指令

| 指令 | 说明 |
| :--- | :--- |
| `/xb2img <图A> <图B>` | 合成图片，默认输出 PNG 格式文件（列表看 A，点开看 B） |
| `/xb2img ./a.jpg ./b.jpg` | 支持本地图片文件绝对路径或相对路径 |
| `/xb2img https://.../a.jpg https://.../b.jpg` | 支持网络图片 HTTP/HTTPS 直链自动下载并合成 |
| `/xb2img` 并在消息中附带两张图片 | 交互式发图：直接在指令后面贴上两张图片一起发送 |
| `/xb2img --apng <图A> <图B>` | 强制以 `.apng` 后缀发出（文件字节一致，仅扩展名不同） |

## 🔬 实现原理

- **本质单文件动图**：插件并不是在协议层分发两个独立资源，而是现场合成一张标准的 APNG 动图（PNG 的动图扩展标准，包含 `acTL`、`fcTL` 等数据块）。
- **帧差分展示机制**：
  - **第 1 帧**：放入预览图 A。QQ 聊天窗口列表在未展开或缩略模式下，默认仅抓取并渲染动图的第一帧静止画面，因此用户一眼看到的是图 A。
  - **第 2 帧及后续**：放入展示图 B。用户在 QQ 窗口中点击图片进入大图浏览/下载原图模式后，客户端动画播放时钟启动，持续播放图 B 的画面。
- **直发与格式兼容**：通过底层图片消息原图形式发出，避免二次转码破坏动图结构；Windows QQ NT 等各主流客户端均可获得极佳的体验。

## 🧾 备注

- 接收端必须支持 APNG 动图播放（Windows QQ NT、各大现代浏览器及主流移动端体验完美）。
- 输入单张图片体积建议控制在 20MB 以内，超出将自动拦截以防内存占用过高。
- 合成过程会自动将过大图片等比缩放并压缩至约 1MB 左右，兼顾网络传输速度与画质。
