# astrbot_plugin_xb2img (QQ双图助手 xb2img)

🖼️ 一个基于 APNG 动画帧特性的 AstrBot QQ“双图”消息生成插件。实现聊天窗口列表显示预览图 A，点击查看原图后播放展示图 B 的神奇视觉效果。

- 📦 项目主页：https://github.com/imsuperone/xb2img

---

## 🌟 核心特性

- 🎭 **两张图两副面孔**：未点开时聊天列表静止显示预览图 A，点开加载原图后播放展示图 B。
- 🔄 **全彩无限循环**：支持全彩 RGBA / RGB 高清图像，循环播放且不降色深。
- 💾 **智能体积压缩**：内置自动多阶梯梯级压缩，自动将最终文件体积控制在 1MB 左右，兼顾极速加载与清晰度。
- 🚦 **多任务并发排队**：自带全局任务排队控制门（最多 5 个任务并发排队保护），防止多人频繁触发导致系统资源耗尽。
- 🧹 **内存与临时文件无残留**：任务处理完毕后立即清理本地临时缓存，零残留不锁盘。
- ⏱️ **交互体验贴心**：处理大图耗时时自动提示“正在处理双图中...”，生成完毕后自动撤回提示，保持聊天窗口整洁。

---

## 🚀 聊天指令

| 指令 | 说明 |
| :--- | :--- |
| `/双图 <图A> <图B>` | 合成双图，默认输出 PNG 格式文件（列表看 A，点开看 B） |
| `/双图 ./a.jpg ./b.jpg` | 支持本地文件路径输入 |
| `/双图 https://.../a.jpg https://.../b.jpg` | 支持网络图片直链下载合成 |
| `/双图` 并在消息中附带两张图片 | 交互式发图：直接在指令后面贴两张图片一起发送 |
| `/双图 --apng <图A> <图B>` | 指定输出文件名为 `.apng` 格式（效果与默认一致） |

## 🔬 实现原理

- **本质单文件动图**：插件并不是在协议层分发两个独立资源，而是现场合成一张标准的 APNG 动图（PNG 的动图扩展标准，包含 `acTL`、`fcTL` 等数据块）。
- **帧差分展示机制**：
  - **第 1 帧**：放入预览图 A。QQ 聊天窗口列表在未展开或缩略模式下，默认仅抓取并渲染动图的第一帧静止画面，因此用户一眼看到的是图 A。
  - **第 2 帧及后续**：放入展示图 B。用户在 QQ 窗口中点击图片进入大图浏览/下载原图模式后，客户端动画播放时钟启动，持续播放图 B 的画面。
- **直发与格式兼容**：通过底层图片消息原图形式发出，避免二次转码破坏动图结构；Windows QQ NT、Android 及各主流平台均可获得极佳的体验。
